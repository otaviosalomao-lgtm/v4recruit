# V4 Recruit — Borges & Co

## Como configurar

### 1. Backend (Google Apps Script)

1. Acesse script.google.com e crie um novo projeto
2. Cole o conteúdo de `backend_api.js`
3. Execute a função `setupInicial` uma vez
4. Clique em **Implantar → Nova implantação**
   - Tipo: App da Web
   - Executar como: Eu
   - Acesso: Qualquer pessoa
5. Copie a URL gerada

### 2. Frontend

1. Abra `App.jsx`
2. Na linha 4, substitua `COLE_AQUI_A_URL_DO_APPS_SCRIPT` pela URL copiada
3. Faça upload desta pasta para o GitHub

### 3. Deploy no Vercel

1. Acesse vercel.com e conecte com o GitHub
2. Importe o repositório
3. Clique em Deploy
